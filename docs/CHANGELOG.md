# Changelog

File này ghi lại các tính năng và thay đổi chính trong quá trình phát triển Admin Portal.

## Tích hợp Tech vào dự án dự án

- Tích hợp Firebase Authentication và Firestore.
- Cấu hình Firebase Emulator để phát triển và kiểm thử trên máy local.
- Xây dựng đăng nhập và phân quyền người dùng.
- Thiết lập quy tắc bảo mật dữ liệu bằng Firestore Security Rules.

## Xây dựng các chức năng quản trị

- Xây dựng Dashboard hiển thị số liệu và biểu đồ.
- Phát triển chức năng quản lý nhân sự: thêm, xem, sửa và xóa.
- Bổ sung tìm kiếm, lọc và phân trang danh sách nhân sự.
- Hiển thị dữ liệu cập nhật theo thời gian thực.
- Ghi lại lịch sử hoạt động của quản trị viên.
- Hiển thị thông báo và các hoạt động gần đây.

## Báo cáo, bảo mật và tối ưu

- Bổ sung chức năng xuất danh sách nhân sự ra file CSV.
- Bổ sung chức năng xuất báo cáo tháng ra file PDF.
- Phát triển cảnh báo cho các thao tác quan trọng, có rủi ro cao.
- Tối ưu phân trang và truy vấn dữ liệu.
- Cải thiện hiệu năng hiển thị bảng dữ liệu và thông báo.
- Bổ sung kiểm thử cho các chức năng liên quan.

## Sao lưu và bàn giao hệ thống

- Xây dựng các script hỗ trợ sao lưu và khôi phục dữ liệu Firestore.
- Bổ sung sơ đồ kiến trúc hệ thống vào README.
- Cập nhật tài liệu hướng dẫn cài đặt và chạy dự án.
- Chuẩn bị tài liệu hướng dẫn sử dụng dành cho quản trị viên.
- Kiểm tra lại cấu hình, chức năng, bảo mật và quy trình bàn giao.
